# Contributing

Thanks for contributing to Awesome AEM GEO.

## Development

Use Java 21 and Maven 3.9 or newer. Run `mvn verify` before opening a pull request. AEM deployment is intentionally opt-in and requires `-Paem-install` with credentials supplied through Maven properties or environment-backed settings.

## Pull requests

- Explain the behavior and public API impact.
- Add or update unit and integration tests.
- Keep generated files and local AEM credentials out of commits.
- Update the README or changelog when user-facing behavior changes.
